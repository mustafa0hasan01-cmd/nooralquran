# تطبيق نور القرآن الكريم لهواتف الأندرويد (Android APK)

تحتوي هذه الحزمة على المشروع الكامل لتطبيق **نور القرآن الكريم** (المصحف الكامل 114 سورة، تلاوات الشيخ ياسر الدوسري مع الانتقال التلقائي للصفحات، الأذكار والسبحة، مواقيت الصلاة العالمية لجميع دول ومدن العالم مع بوصلة القبلة الدقيقة، إشعارات التسبيح الساعية بصوت الدوسري وإشعارات الأذان، ولوحة تحكم الأدمن المخفية).

---

## ٣ طرق سهلة لتثبيت التطبيق أو استخراج ملف `.apk` على هاتفك:

### الطريقة الأولى (الأسرع — من الهاتف مباشرة بدون كمبيوتر):
1. افتح ملف التطبيق (`quran_app.html` أو `www/index.html`) في متصفح **Google Chrome** على هاتفك الأندرويد.
2. اضغط على زر **«تطبيق أندرويد APK»** الذهبي في الشريط العلوي للتطبيق، ثم اضغط **«تثبيت التطبيق على الهاتف الآن»** (أو من قائمة المتصفح `⋮` اختر **تثبيت التطبيق / Install App**).
3. سيتم تثبيت التطبيق كحزمة أندرويد مستقلة (**WebAPK**) على شاشة هاتفك الرئيسية ويعمل بملء الشاشة الكامل.

---

### الطريقة الثانية (استخراج ملف `.apk` سحابياً مجاناً عبر GitHub بدون تثبيت أي برامج):
1. ارفع محتويات هذا المجلد إلى مستودع جديد على حسابك في **GitHub**.
2. انتقل إلى تبويب **Actions** داخل المستودع واضغط على **Build Noor Al-Quran Android APK**.
3. خلال دقيقتين فقط سيقوم الخادم ببناء وتجهيز ملف **`Noor-AlQuran-Android-APK.apk`** جاهزاً للتحميل والتثبيت المباشر على أي هاتف أندرويد.

---

### الطريقة الثالثة (عبر Android Studio أو أدوات تحويل HTML إلى APK):
* **باستخدام Android Studio**: افتح هذا المجلد مباشرة في برنامج Android Studio، ثم اختر من القائمة العلوية:
  `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`
  ليتم توليد ملف `app-debug.apk` جاهزاً للتثبيت.
* **باستخدام برنامج Website 2 APK Builder أو Cordova/Capacitor**:
  الملف الجاهز موجود داخل `app/src/main/assets/index.html` و `www/index.html` بجميع الصلاحيات والخطوط والميزات.
